WORKFLOW

一条完整的尾盘交易链路

从全市场初筛到次日退出，每个环节都有明确的输入、硬性条件与可审计输出。

14:31 · 初筛

全市场强势股筛选

按涨幅区间、成交额、换手率、量比过滤，再叠加日 K 位置与 10 分钟均线结构。

  • 涨幅 3% ~ 8% 初筛池
  • 日 K 启动形态 A / B 分类
  • 尾盘强度与量能配合评分
14:51 · 确认

二次校验与买入清单

按最新行情复核候选，硬性条件失败即淘汰，最多生成 5 只买入标的。

  • 止损价与盈亏比测算
  • 持仓退出优先处理
  • Markdown + JSON 双输出
次日 · 退出

开盘决断与盘中巡检

9:35 按开盘情景 A–E 判定，冲高卖出或继续观察，14:51 最迟退出。

  • 每半小时持仓状态巡检
  • 次日冲高与回落监控
  • 周 / 月复盘沉淀参数
CAPABILITIES

为「可验证」而设计

不追求复杂框架，把数据校验、时点一致性和复盘闭环做扎实。

零依赖单文件引擎

只用 Python 标准库，复制即可运行，部署成本极低，便于审计与二次开发。

无未来函数

10 分钟 K 线只使用已收盘 bar，日 K 当日 bar 明确标记「进行中」，复算也不会读取未来数据。

三层数据校验

行情自洽 → 东财与腾讯双源交叉 → K 线历史合法性检查，关键失败不出交易名单。

结构化报告

候选、买入清单、持仓监控、周月总结均为 Markdown + JSON，人读与机器复盘两不误。

影子跟踪

对初筛池做「假设买入」前向跟踪，扩大样本，检验每个筛选关卡是否在漏掉好票。

复盘与参数迭代

胜率、盈亏比、最大回撤、选股漏斗与分档统计，用数据决定参数是否值得调整。

ARCHITECTURE

数据 → 引擎 → 可审计输出

单进程、无外部服务依赖；所有中间结果落盘，失败可追溯。

三分钟跑起来

只需要 Python 3.8+ 和可访问行情接口的网络环境。

bash · stock-strategy
# 1. 克隆仓库 git clone git@github.com:kangkangxi/stock-strategy.git cd stock-strategy # 2. 生成本地配置（不会提交） cp config.example.json config.json # 3. 查看持仓与统计 python3 scripts/tail_momentum.py --mode status # 4. 试跑尾盘初筛：只出报告，不推送 python3 scripts/tail_momentum.py --mode scan --dry-run → 报告/尾盘选股_YYYY-MM-DD.md
运行时目录

首次运行会自动创建 报告/、日志/ 与 positions.json，这些均被 .gitignore 排除。

推送默认关闭

需要通知时，把 config.json 的 push 设为 true，并提供自己的 wecom_push.py。

隐私提醒

positions.json、报告/、日志/ 含真实交易数据，请勿提交到公开仓库。
